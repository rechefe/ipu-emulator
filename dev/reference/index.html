    Reference¶

    These pages are for looking things up: instructions, operands, commands and terms.

    Page What it covers
    Instructions Every instruction, by slot, generated from instruction_spec.py.
    Operand types The operand types the instruction reference uses.
    Assembly syntax Instruction words, separators, labels, registers and Jinja2 preprocessing.
    Instruction format The bit layout of the instruction word, and the SystemVerilog package download.
    Programmer's guide The pseudo-instructions the assembler expands, such as BGT.S and BZ.
    Registers Every register, its size and its assembly names.
    Configuration registers The CR constants, the CR halves (DS and QF layouts) and the MULT constant.
    ACTIVATE.QUANTIZE, ACTIVATE.EXACT and LD.LUT The AaQ stage: activation, NX8 quantization, the store and the LUT.
    kernel.toml Every key of a kernel's kernel.toml and a family's registry.toml, generated from the loader.
    Command-line tools Every command-line tool (ipu-as, the kernel runner and the debugger), with its subcommands and options.
    Reference model API The stable emulator API and the trace schema.
    Kernels The kernel catalogue, by family.
    Code conventions How code in this repository is written, and what checks each rule.
    Code review What a PR author states and runs, and what reviewers check beyond CI.
    Glossary The terms these docs use.
