    Instruction format¶

    This page describes the binary layout of a single IPU compound (VLIW) instruction. Field names, bit widths, opcode values, and union-field sharing are generated from instruction_spec.py in ipu_isa (the same source the assembler and emulator use).

    Hardware word (155 bits)¶

    The part of the instruction word the IPU decodes: the hardware slots (COND, LR×3, LOAD, MULT, ACC, AAQ, STORE). The SystemVerilog package describes this word (IPU_COMPOUND_INST_WIDTH = 155).

    Emulator word (186 bits)¶

    The word the emulator decodes and .bin files hold: the hardware word followed by the emulator-only slots (ACC_STORE, BREAK) below its bit 0. Its top 155 bits are the hardware word.

    Generated artifacts¶

    These files are produced at documentation build time (and via the ipu-gen CLI). They are not checked into the repository.

    Artifact Description Download
    SystemVerilog package ipu_instr_pkg — enums, per-slot structs (opcode + operand union), per-instruction union packed views, the hardware word as the compound type ipu_instr_pkg.sv

    Regenerate locally¶

    bazel build //docs:generate_instruction_format_artifacts
# outputs under bazel-bin/docs/

bazel run //src/ipu-gen:ipu-gen -- sv-package --output /tmp/ipu_instr_pkg.sv
