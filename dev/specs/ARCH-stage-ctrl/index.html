    Control Stage¶

    1. Overview¶

    The CTRL (Control) stage is the first stage of the IPU. It performs the following tasks:

    • Fetch: Fetches one word per clock cycle from the active IMEM bank.
    • Branch: Executes the COND slot and updates the PC.
    • Loop registers: Executes the three LR slots.
    • Operands: Resolves the CR and LR operands of the later stages.
    • XMEM address: Computes the row address of each load and store.
    • Stall: Stalls on an XMEM miss.

    3. Interfaces¶

    Name Direction Description
    Host Input Kernels and CR values (IPU ARCH 12).
    XMEM status Input Whether the XMEM rows of a word are ready.
    Instruction Output The LOAD, MULT, ACC and AAQ slots of a word and their operand values, to the later stages.
    XMEM read address Output The row that a load reads, to XMEM.
    XMEM write address Output The row that a store writes, to the AaQ stage.

    3.1 Fetch¶

    The stage fetches the word at the PC from the IMEM bank of the active context. The COND slot of that word sets the next PC. A taken branch costs no extra cycle.

    3.2 Operand Resolution¶

    The stage reads every CR and LR operand of the LOAD, MULT, ACC and AAQ slots and sends the values with the slot. The later stages do not read the CR and LR files. IPU ARCH 6.3 gives the value of each read.

    3.3 XMEM Address¶

    The stage computes the row address of each XMEM access (IPU ARCH 9):

    Instruction Access Base CR Offset LR
    LD.MULT, LD.MULT.CYCLIC, LD.MASK Read base offset
    LD.LUT Read table_id table_offset
    ACTIVATE.QUANTIZE Write table_id table_offset

    3.4 Stalls¶

    The stage stalls a word until its XMEM rows are ready. A stalled word changes no state: its LR writes and its PC update take effect when it moves on.

    4. Control ISA¶

    The stage executes the COND slot and the three LR slots of each word.

    The opcode enums (cond_inst_opcode_t and lr_inst_opcode_t, package ipu_instr_pkg) are generated from instruction_spec.py by sv_package.py.

    Note: Two LR slots of one word cannot write the same LR.

    Instructions in this section:

    Instruction Slot Purpose
    NOP LR, COND Do nothing.
    SET LR Copy a value into an LR.
    ADD, SUB LR Add or subtract two registers.
    INC, DEC LR Add an immediate to an LR, or subtract it.
    INC.MODP2 LR Add to an LR modulo a power of two.
    ADDB, ADDBI LR Add a byte to all 8 bytes of an LRD.
    BEQ, BNE, BLT.S, BGE.S COND Branch on a comparison.
    BR COND Branch to the address in a register.
    HALT COND End the kernel.

    4.1 NOP: No Operation¶

    No operation for the slot. In the COND slot, the PC moves to PC + 1.

    Syntax¶

    NOP

    Operands¶

    None.

    Example¶

    NOP;;

    4.2 SET: Set Loop Register¶

    Copies a value into an LR.

    Syntax¶

    SET reg src

    Operands¶

    Name Type Details
    reg LrIdx LR0-LR15. The destination.
    src LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. The source. A half is sign-extended (IPU ARCH 8.5).

    Operation¶

    reg = src

    Example¶

    SET LR0 CR1;;
SET LR1 CR5.H;;

    4.3 ADD, SUB: Add and Subtract¶

    Adds or subtracts two registers. The result wraps at 32 bits.

    Syntax¶

    ADD dest src_a src_b
SUB dest src_a src_b

    Operands¶

    Name Type Details
    dest LrIdx LR0-LR15. The destination.
    src_a LrIdx LR0-LR15. The first source.
    src_b LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. The second source. A half is sign-extended.

    Operation¶

    Mnemonic dest becomes
    ADD (src_a + src_b)[31:0]
    SUB (src_a - src_b)[31:0]

    Example¶

    ADD LR0 LR1 LR2;;
SUB LR3 LR1 CR5;;

    4.4 INC, DEC: Increment and Decrement¶

    Adds an unsigned immediate to an LR, or subtracts it. The result wraps at 32 bits.

    Syntax¶

    INC dest imm
DEC dest imm

    Operands¶

    Name Type Details
    dest LrIdx LR0-LR15. The source and the destination.
    imm Imm 0-255. The unsigned step.

    Operation¶

    Mnemonic dest becomes
    INC (dest + imm)[31:0]
    DEC (dest - imm)[31:0]

    Example¶

    INC LR0 7;;
DEC LR0 3;;

    4.5 INC.MODP2: Increment Modulo a Power of Two¶

    Adds a register to an LR, then keeps the low k bits.

    Syntax¶

    INC.MODP2 dest step k

    Operands¶

    Name Type Details
    dest LrIdx LR0-LR15. The source and the destination.
    step LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. The step. A half is sign-extended.
    k Imm 1-9. The number of bits kept.

    Operation¶

    dest = (dest + step) & ((1 << k) - 1)

    Example¶

    INC.MODP2 LR2 LR3 4;;      // LR2 = (LR2 + LR3) mod 16

    4.6 ADDB, ADDBI: Add Byte, Broadcast¶

    Adds one signed byte to each of the 8 byte elements of an LRD. Each element saturates to 0-255.

    Syntax¶

    ADDB dest src_b
ADDBI dest imm

    Operands¶

    Name Type Details
    dest LrdIdx LRD0, LRD2, ..., LRD14. The source and the destination (IPU ARCH 4.2).
    src_b LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. ADDB reads its low byte.
    imm Imm -128-255. ADDBI reads it as a byte.

    Operation¶

    value = signed_byte(src_b[7:0])          // ADDB
value = signed_byte(imm)                 // ADDBI

for k in 0..7:
    dest.element[k] = clamp(dest.element[k] + value, 0, 255)

    Example¶

    ADDB LRD0 LR3;;
ADDBI LRD2 -56;;

    4.7 BEQ, BNE, BLT.S, BGE.S: Conditional Branch¶

    Compares two registers and branches to label when the condition holds.

    Syntax¶

    BEQ reg1 reg2 label
BNE reg1 reg2 label
BLT.S reg1 reg2 label
BGE.S reg1 reg2 label

    Operands¶

    Name Type Details
    reg1 LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. The first register. A half is sign-extended.
    reg2 LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. The second register. A half is sign-extended.
    label Label 0-1023. The branch target.

    Operation¶

    Mnemonic Taken when
    BEQ reg1 == reg2
    BNE reg1 != reg2
    BLT.S reg1 < reg2, as signed integers
    BGE.S reg1 >= reg2, as signed integers 
    PC = taken ? label : PC + 1

    Example¶

    BNE LR0 CR2 loop;;
BLT.S LR0 CR1 smaller;;

    4.8 BR: Branch Register¶

    Branches to the address in a register.

    Syntax¶

    BR reg

    Operands¶

    Name Type Details
    reg LcrHalfIdx LR0-LR15, CR0-CR15 or CR0.L-CR15.H. The target. A half is sign-extended.

    Operation¶

    PC = reg

    Example¶

    BR LR0;;

    4.9 HALT: End the Kernel¶

    Ends the kernel. The other slots of the word execute, and the stage fetches no further word. The kernel is done when the word retires.

    Note: The host's HALT command is a separate operation (IPU ARCH 10).

    Syntax¶

    HALT

    Operands¶

    None.

    Example¶

    HALT;;

    5. Disagreements with the Emulator¶

    Topic Spec Emulator
    BR target above the last IMEM word PC has log2(IMEM_BANK_DEPTH) bits (IPU ARCH 4). Uses the full 32-bit value and stops the run.
    PC after HALT PC has log2(IMEM_BANK_DEPTH) bits, so 1024 does not fit. 1024, one past the last IMEM word.

    IPU ARCH 14 lists the differences in contexts, stalls and row addresses.
