Hardware pipeline

Blocks and paths lit in a slot's colour are used by the word just executed. Register chips turn yellow when the word wrote them. Block layout follows docs/content/requirements/architecture.md.
Timing model: each word enters CTRL one clock after the previous one and spends one clock per stage, with no cache stalls. The spec fixes each stage's latency but does not yet give the values (IPU-ARCH-12). The emulator executes every word atomically; pipelining changes timing only, never results (IPU-ARCH-13). Hollow cells are bubbles: the word has no operation for that stage.
