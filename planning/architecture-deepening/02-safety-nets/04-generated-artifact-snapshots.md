# Snapshot `isa.json`, the TextMate grammar and the generated docs pages

Part of [Epic E02: Safety nets before the refactors](00-epic.md) · ID E02-04 · Size S · Depends on: E01 (toolchain pin) · Behaviour change: none · `*_WIDTH` localparams: not affected (SV package is E02-03)

## Goal

Pin every artifact generated from `instruction_spec.py` other than the SV package, so the ISA package refactors (E03) and the generator move to `ipu_gen` (E08) are proven output-identical, and intended changes show as readable text diffs in review.

## Background

Generated today, none of them compared with a recorded value:

| Bazel target | Outputs | Generator |
|---|---|---|
| `//docs:generate_mkdocs_md` | `instructions.md`, `operand-types.md`, `assembly-syntax.md`, `programmer-guide.md` | `ipu_as/gen_docs.py` via `docs/gen_docs_wrapper.py` |
| `//docs:generate_instruction_format_md` | `instruction-format.md` | `gen_docs.generate_instruction_format_md` |
| `//vscode-ipu-asm:generate_grammar` | `syntaxes/ipu-asm.tmLanguage.json`, `language-configuration.json`, `data/isa.json` | `ipu_as/gen_vscode.py` |
| `//src/tools/ipu-common:gen_union_layout_svg` (`bazel run`) | union layout SVG | `ipu_common/union_layout_svg.py` |

- `test_isa_data.py` and `test_hover_data.py` check properties of `isa.json` (every type described, examples assemble), not its content.
- `gen_vscode._normalize_asm_snippet` (`gen_vscode.py:393-405`) rewrites commas out of `syntax`/`example` because the spec writes them with commas. E03 removes the commas at the source; this snapshot proves the shipped `isa.json` does not change when it does.

## Implementation

1. Add `src/tools/ipu-as-py/test/baselines/generated/` holding checked-in copies of the 8 text outputs above (the SVG rendered with fixed arguments, as `gen_union_layout_svg` does).
2. Add `//src/tools/ipu-as-py:test_generated_artifacts`. It regenerates each artifact in-process (calling the same functions the wrappers call, not the genrules, so it does not depend on stamping) and compares byte-for-byte. A failure prints a unified diff limited to 80 lines plus the file name.
3. Add `py_binary(name = "update_generated_artifacts")` that rewrites the directory.
4. Each artifact's entry records the producing function, so when E08 moves a generator the test changes one import line, not its expectations.

## Risks

- `instructions.md` and `isa.json` change in many E03 issues by design (derived syntax, rename, tags). Those issues regenerate the snapshot and the reviewer reads the text diff. Refactor-only issues must leave it untouched.
- If a generator embeds a timestamp or path, normalize it in the test, not in the generator, and list the normalization in the test file.
