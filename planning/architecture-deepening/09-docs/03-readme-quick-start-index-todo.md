# README Quick Start, docs home page facts, remove TODO.md

Part of [Epic E09: Documentation restructure](00-epic.md) · ID E09-03 · Size S · Depends on: none · Behaviour change: none

## Goal

The first two pages a visitor sees (GitHub `README.md` and the docs home page)
state correct facts and give a working first command. `TODO.md` no longer
competes with GitHub Issues.

## Background

- `README.md:20-22`: the "Quick Start" heading has no content.
- `README.md:9-17` lists three packages and calls `ipu_common` the single
  source of truth. The package list changes with the E03 package split (Q69);
  this issue only fixes what is wrong today.
- `docs/content/index.md:3-11` describes a "C-based emulator" and "C-based
  emulator for IPU behavior". The emulator is Python.
- `docs/content/index.md:28-40` shows a repository tree for `ipu-c-samples/`
  with `src/apps/`, `src/lib/` and `test/`, none of which exist.
- `TODO.md` (7 lines): "Write basic kernel for softmax", "Write basic kernel for
  CNN" and the LR "union" item are done (`kernels/softmax/`,
  `kernels/convolutions/`, `union_layout.py`). The remaining items
  (quantization, template defines, register metadata) are either decided
  elsewhere (AaQ is an open question, `--define` is E05) or belong in issues.

## Implementation

1. `README.md` "Quick Start": three steps, each a command that works today.
   - Prerequisites: Bazelisk (link `docs/content/setup.md`).
   - `bazel test //...`
   - `bazel run //src/tools/ipu-apps:identity` (runs one kernel end to end).
   - One line linking the docs site.

   E09-08 replaces the commands when E01 adds the pinned bootstrap script and
   E06 changes how kernels run.
2. `docs/content/index.md`: replace the overview and the repository tree with
   a correct short description (Python emulator, assembler, kernels, Bazel)
   and a tree generated by hand from `ls src/tools`. Keep it to the top two
   levels so it survives small moves. E09-06 rewrites the rest of the page.
3. Delete `TODO.md`. Before deleting, open GitHub issues for the items that are
   still wanted, or confirm they are covered:
   - "Implement quantization" → the AaQ open question (E09-05).
   - "Add preprocessing CLI options" → E05 `--define`.
   - "Add Metadata to registers and XMEM" → ask the user whether it is still
     wanted. Open question.
