Glossary

The terms this course uses, named as in the repo specs. A term joins this list once you have shown you can use it.

Rows

TermDefinitionAvoid
Row128 elements of 8 bits (1024 bits) at one XMEM row address, plus its metadata word.line, word
Metadata wordThe 16 bits stored beside every row: scale[7:0], dynamic_exponent[8], reserved [15:9].header, sideband
ScaleThe row's shared exponent s, e8m0 with bias 127: the largest raw FP32 exponent among the row's elements.scale factor, for the exponent itself
dynamic_exponentMetadata bit 8: the split AaQ chose for a row of a dynamic table, 0 = E1M6, 1 = E2M5.
Block scalingSharing one scale across a block of elements so each element stores only its offset from it. AaQ's block is one row; OCP MX uses 32 elements.

Tables

TermDefinitionAvoid
Table formatThe 9-bit format of a table, {dynamic, sign, fe, W}. Shared by every row of the table and never written to XMEM.row format
Table setThe tables of one kernel, at most 16, held by the cache unit. There are two, one per context.
ContextOne IMEM bank, one CR bank and one table set, selected together by active_ctx.
Cache agentThe IPU stage that decides hit or miss for each word's memory accesses, from its read-only copy of the table sets (tbl_view) and the bank tags.CRM, cache unit
feThe number of exponent bits in an element: from the table format, or from dynamic_exponent in a dynamic table.

Direct branchQuantizer path for E < 2fe − 1: Exp = E, mantissa rounded to fm bits.4
Clamp branchQuantizer path for larger E: exponent field all ones, mantissa shifted right so small values keep their magnitude.4
Edge 1, edge 2Rounding that carries out of the mantissa, in the direct branch (edge 1) or the clamp branch (edge 2).4
Dynamic tableA table with dynamic = 1: signed, W = 8, and AaQ picks E1M6 or E2M5 for each row.5
SplitOne division of an element's bits between exponent and mantissa at a fixed width, such as E1M6 or E2M5.5
Accumulators A and BThe §5.1.1 integer sums: A estimates what E2M5 loses at the scale, B what E1M6 loses from E = 2 down.5
LUTThe AaQ stage's 256 × 17-bit lookup table for generic, exp2, reciprocal and rsqrt.6
LUT metadataThe 75-bit block loaded with the LUT that sets out-of-range handling. Unrelated to a row's metadata word.6
LUT loadThe AAQ-slot instruction (proposed AAQ.LUT.LD) that copies one 1024-bit segment from R_ACC words 0–31 into the LUT.6
ExpansionTurning a stored byte back into its FP32 value from the row's scale and the table's fe.7
Window straddleA 128-element read window that covers rows with different metadata words.7
GoldenA kernel case's expected output, held by its test. Distinct from a baseline, a checked-in snapshot file.8
