Metadata word (16 bits per 1024-bit row)

BitsFieldMeaning
[7:0]scaleShared exponent, e8m0 (bias 127): the largest raw FP32 exponent in the row.
[8]dynamic_exponent0 = E1M6, 1 = E2M5. 0 and ignored in static tables.
[15:9]reservedUnused.

Source: cache unit §4, §6. The AaQ payload (AaQ §3.2) is 1024 + 8 + 1 = 1033 bits.

Table format (9 bits, not in XMEM)

BitsFieldMeaning
[8]dynamic0 = static, 1 = dynamic (signed, W = 8, E1M6 or E2M5 per row).
[7]sign0 = unsigned, 1 = signed.
[6:4]feExponent bits. Ignored when dynamic.
[3:0]WElement width, 1–8. Mantissa fm = W − fe − sign; low bits zero-padded when W < 8.

Source: AaQ §3.3, cache unit §5.

Decode one element (signed, W = 8)

Exponent fieldValue
Exp < 2fe − 1±(1 + M/2fm) · 2s − 127 − Exp
Exp = 2fe − 1 (clamp)±(M/2fm) · 2s − 127 − 2fe + 2

A larger exponent field means a smaller value: Exp counts binades below the scale. This differs from the emulator's E1–E7 formats, whose exponent field is biased the IEEE way.

Proposed: inverted from AaQ §5.1. No spec defines the decode.

Worked example: s = 128, fe = 4, byte 0x1D = 0 0011 101 → (1 + 5/8) · 2−2 = 0.40625. The same byte with fe = 2 → 3.8125.

Open gaps

  • No MULT-stage spec: the expansion to FP32 is undefined.
  • fe = 0: allowed by AaQ §3.3, forbidden by AaQ §5.1.
